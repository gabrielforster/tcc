Página de exemplo

Esta página existe para ver o widget funcionando como um site externo o veria. O botão no canto inferior direito abre a conversa.

Como embedar

<script src="https://SEU-HOST/chat/widget.js"
        data-api="https://SEU-HOST"
        data-title="Atendimento"
        defer></script>

Identificando o cliente

Sem token a conversa é anônima e responde qualquer coisa da base de conhecimento (política, FAQ, tabela de parcelamento). Para identificar o cliente, o backend da aplicação gera o token e o entrega à página: 

from collection.channels.session import issue_token

token = issue_token(customer_id)  # nunca no navegador
<script src="https://SEU-HOST/chat/widget.js"
        data-api="https://SEU-HOST"
        data-token="{{ token }}"
        defer></script>

O que testar aqui

  • quais sao os juros e a multa por atraso? — resposta ancorada no FAQ
  • posso parcelar em 6 vezes? — tabela de parcelamento
  • esse valor ta errado, nao e isso que eu devo — contestação, escala para humano
  • parem de me mandar mensagem — opt-out registrado

O botão acima está estilizado com uma regra global agressiva (button { background: hotpink }). Se o botão do widget continuar azul, o isolamento por shadow DOM está funcionando.
