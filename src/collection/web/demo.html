Demonstração 01 · Chat

Converse com o agente

Esta página faz o papel do site de uma empresa que embutiu o widget de atendimento. O botão verde no canto inferior direito abre a conversa.

Se a conversa já abrir com uma mensagem, foi o agente proativo: ele escreveu o contato, o verificador de conformidade aprovou, e a mensagem esperou aqui até você abrir o chat.

O que testar

  • quais sao os juros e a multa por atraso? — resposta ancorada no FAQ
  • posso parcelar em 6 vezes? — tabela de parcelamento
  • esse valor ta errado, nao e isso que eu devo — contestação, escala para humano
  • parem de me mandar mensagem — pedido para não ser mais contatado, registrado
  • segure o botão do microfone e fale um valor — o widget grava, envia e, quando o valor falado precisa de confirmação, mostra a leitura de volta em destaque
  • os tiques de cada mensagem enviada refletem o que o servidor registrou: entregue quando a mensagem aparece, lida quando está à vista

Numa conversa real o cliente não veria tiques nas mensagens que recebeu: eles são o recibo do operador, e aparecem aqui no widget só para que o mecanismo fique visível durante a demonstração.

Como embutir

<script src="https://SEU-HOST/chat/widget.js"
        data-api="https://SEU-HOST"
        data-title="Atendimento"
        defer></script>

Identificando o cliente

Sem token a conversa é anônima e responde qualquer coisa da base de conhecimento (política, FAQ, tabela de parcelamento). Para identificar o cliente, o backend da aplicação gera o token e o entrega à página: 

from collection.channels.session import issue_token

token = issue_token(customer_id)  # nunca no navegador
<script src="https://SEU-HOST/chat/widget.js"
        data-api="https://SEU-HOST"
        data-token="{{ token }}"
        defer></script>

Isolamento

O botão abaixo está estilizado com uma regra global agressiva (button { background: hotpink }). Se o botão do widget continuar verde, o isolamento por shadow DOM está funcionando.
